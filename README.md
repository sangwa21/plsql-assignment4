# Student Registration and Grading Management System

## 1. Project Overview
This project is an Oracle PL/SQL application for managing students, courses, registrations, and grades.

## 2. Database Tables
- STUDENTS
- COURSES
- REGISTRATIONS
- GRADES

## 3. PL/SQL Concepts Demonstrated
- User-defined records and %ROWTYPE
- Associative arrays
- Implicit cursors
- Explicit cursors
- BULK COLLECT and FORALL
- Stored procedures
- Functions
- Exception handling

## 4. Procedures
- REGISTER_STUDENT: Registers students for courses.
- APPLY_GRADE_BONUS: Applies a bonus to student grades using bulk processing.

## 5. Function
- GET_STUDENT_AVERAGE: Calculates a student's average grade.

## 6. Testing
Both successful and error test cases were executed.

## 7. How to Run
1. Run the table creation script.
2. Run the sample data script.
3. Compile the PL/SQL procedures.
4. Compile the function.
5. Run the success and error test scripts.
